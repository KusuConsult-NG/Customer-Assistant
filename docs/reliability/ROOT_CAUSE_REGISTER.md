# Root Cause Register — Plateau State Citizen Contact Centre

This register records every recurring or high-impact failure investigated during production stabilisation, its verified root cause, the durable fix applied, and the regression guard preventing recurrence.

| ID | Incident / Symptom | Verified Root Cause | Durable Fix | Regression Guard | Status |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **RC-01** | Agent spoke `"full stop"` and `"comma"` aloud during calls | Spitch TTS vocalised punctuation tokens (`,`, `.`, `:`) in certain Nigerian English phrasing | `SpitchTts.synthesize()` normalises/strips commas and sentence-final periods/colons before API submission | `apps/api/test/voice-local-tts.spec.ts` punctuation sanitisation tests + live Whisper verification | **Resolved (Live)** |
| **RC-02** | Excessive `"One second, please"` / `"Let me check"` fillers made calls sound robotic | Two overlapping triggers: (a) synthetic `LOCAL_VOICE_ACK_AFTER_MS` timer firing during normal turn latency; (b) `agent-tool-catalog.ts` instructing LLM to speak lookup bridges before tool calls | Set `LOCAL_VOICE_ACK_AFTER_MS=0` in production and removed lookup-bridge instructions from `agent-tool-catalog.ts` (`ad65857`) | Unit tests in `voice-local.spec.ts` (configurable env override preserved) | **Resolved (Live)** |
| **RC-03** | Governor greeting delayed, stuttered, or bled `"distinguished guests"` | Old cloned voice reference audio contained extraneous speech; live synthesis on call start incurred cold API latency | Cloned studio-grade Governor voice (`SPITCH_GOVERNOR_VOICE`) with exact verbatim transcript and pre-rendered all 3 time-of-day greetings (`Good morning` / `Good afternoon` / `Good evening`) + `jude`/`lucy` NDPA clips to `/data/files/tts-cache` | Pre-rendered cache verification + Whisper transcription audit | **Resolved (Live)** |
| **RC-04** | Agent misheard `"Governor's"` as `"nurse"` and line sounded choppy | `6.7%–30%` UDP packet loss on carrier path Hop 9 (`197.253.11.119`) dropped RTP frames (`"Gover-"`); no adaptive jitter buffer on AudioSocket leg | Enabled `JITTERBUFFER(adaptive)=300,60,40` on Asterisk AudioSocket leg + µ-law ASR fix (`b46bbad`) + anti-aliased 24kHz→8kHz resampler (`3a07271`) | `voice-local-tts.spec.ts` stopband attenuation tests (`<-60 dB` aliasing); AlphaTech carrier escalation still required | **Mitigated (Carrier Escalation Open)** |
| **RC-05** | `HTTP 429 concurrency_limit_exceeded` from Spitch during overlapping utterances | Spitch account is Tier 1 (`3 concurrent requests` max); unbounded parallel TTS calls triggered 429s and silence | Added in-process Spitch concurrency semaphore (max 2 in-flight) + 429 backoff retry (`80ff112`) + **circuit breaker** (`SPITCH_CB_THRESHOLD=3`, 30s cooldown) + 0ms fast-fail in `LocalVoiceService.register()` to ElevenLabs | `voice-local-tts.spec.ts` concurrency gate + circuit breaker regression tests; Spitch tier upgrade still required for 30 calls | **Mitigated (Vendor Upgrade Open)** |
| **RC-06** | Docker build failed on MTN server with `permission denied` | Nightly `ace-backup.timer` wrote `root:root 0700` archives under `deploy/single-server/backups/`, which were inside Docker's build context | Excluded `deploy/single-server/backups` and `deploy/single-server/server.env` in `.dockerignore` | Verified clean `.dockerignore` rules; prevents secret leakage into image context too | **Fixed on Branch** |
| **RC-07** | Nightly backups omitted Qdrant vectors and stayed on local disk | `backup.sh` dumped PostgreSQL and `/data/files` only; `BACKUP_REMOTE` was empty and archives were unencrypted | Added Qdrant collection snapshot (`qdrant.snapshot`) + `SHA256SUMS` coverage + optional AES-256-CBC PBKDF2 encryption (`BACKUP_ENCRYPTION_KEY`) in `backup.sh` | `bash -n deploy/single-server/backup.sh` + `deploy-env-accounting.spec.ts`; User must configure `BACKUP_REMOTE` | **Code Fixed (Off-Server Remote Open)** |
| **RC-08** | Containers could starve each other or start `api` before `qdrant` was ready | `docker-compose.yml` lacked `mem_limit`, `pids_limit`, `stop_grace_period`, and `qdrant`/`web` healthchecks | Added explicit `mem_limit`, `pids_limit`, `stop_grace_period: 30s` to all core containers, added `qdrant` & `web` healthchecks, and gated `api` on `qdrant: service_healthy` | `docker compose config` validation | **Fixed on Branch** |
| **RC-09** | Potential risk of caching citizen PII in shared `tts-cache` | Dynamic TTS responses containing caller names, phone numbers, or ticket numbers must never be reused across callers | Verified and locked down `isCacheable()` guard in `apps/api/src/voice-local/tts.ts` | New dedicated PII non-caching regression test in `voice-local-tts.spec.ts` | **Verified & Guarded** |
| **RC-10** | High ElevenLabs voice cost (`$0.1964/min`) | Default ElevenLabs & local voice LLM was `gpt-4o` (57.8% of total call cost) and ElevenLabs was handling 100% of calls | Switched default LLM to `gpt-4o-mini` (`50093e7`) and migrated primary voice pipeline to local Deepgram + OpenAI + Spitch with ElevenLabs as warm backup | Cost audit verified; ElevenLabs agent patched | **Resolved (Live)** |
| **RC-11** | Internal `tinyurl.com/accountabilityhub` URL risked leaking to callers | Scraped Accountability Hub source text contained internal short URL | Scrubbed all occurrences across 16 Markdown docs and reindexed Qdrant (369 chunks, `0` leaks) | Verified `0` matches across repo and Qdrant | **Resolved (Live)** |
